# Hello CLI

A local Python command line program that prints a greeting. It has no network services, credentials, configuration files or third-party runtime dependencies. This is a demonstration fixture, not a production product.

```sh
python -m pip install -r requirements.txt
python app.py --check
python app.py Ada
python -m unittest discover -s tests -v
```

The first command installs no additional packages. Verification uses Python's standard library. The source, test suite and MIT license should be included in an export. There is no recorded demo or benchmark data. A visual may use the project title and demonstrated CLI behavior, with no invented performance claims.
