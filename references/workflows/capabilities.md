# Capability and metric presentation

For metrics require evidence and as-of date for every number; choose comparison, units and scale for the reader's question. Load Tufte reviewer references only for a quantitative chart and select chart/checklist references at that step. Never replace missing data with invented percentages.

For unmeasured projects, use an evidence-backed categorical table or SVG matrix: capability, implementation status and source/limitation. Separate implemented, designed and unavailable. Status categories are not performance measurements. Keep the final artifact consumed by README/docs. Use internal composition when no decision deck is requested.
