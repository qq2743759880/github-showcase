# Capability binding index

`bindings.json` lists phase pointers and roles. Read the selected `phases/Fxx.json` only. Use `scripts/route-plan.py` to create the per-run plan.

Four integrated workflows: c4-architecture (software semantics), archify (typed diagram authoring and complete interactive delivery), snap-x (identity visuals), readme-skill (README composition). Internal composition owns bounded facts, capability decisions and release delivery. The secret scanner engine is a utility.

Load good-readme only for an independent README audit, Tufte only for an actual quantitative chart review, and og-image-design only for social image QA. Their findings improve the producer's artifact; they cannot replace it or override safety.

Full UX design, CLI recording and video editing are external extensions in `extensions.json`, with explicit triggers and upstream licenses. No extension is installed, invoked or claimed verified by default.
